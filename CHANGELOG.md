# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Production-ready build pipeline with Vite, PostCSS, and autoprefixer
- TypeScript configuration and type definitions for React UI kit
- ESLint, Prettier, and Stylelint configurations for code quality
- Modular CSS architecture splitting monolithic file into logical imports
- GitHub Actions CI/CD workflow for automated testing and publishing
- Vitest testing framework with initial test suite
- Accessibility testing setup with axe-core
- Semantic-release for automated versioning and changelog generation
- `.gitignore`, `LICENSE`, `CHANGELOG.md`, and `CONTRIBUTING.md`
- Package exports map for modern module resolution (ESM/CJS/UMD)
- Self-hosted Geist font strategy with CDN fallback

### Changed
- Converted React UI kit from plain JS to TypeScript with proper component patterns
- Refactored CSS to eliminate hard-coded colors in favor of design tokens
- Updated `package.json` with proper `exports`, `engines`, and `types` fields

### Fixed
- Missing `dist/` directory issue — now generated by build pipeline
- Token inconsistency in component classes using literal hex values

## [1.0.0-alpha.1] - 2024-XX-XX

### Added
- Initial design system implementation
- Complete CSS token system with 11-step color ramps
- 40+ components with 1-bit manga aesthetic
- 20+ animations with retro digital feel
- Geist Sans, Geist Mono, and Geist Pixel font system
- 10 texture categories (scanline, halftone, dot matrix, etc.)
- Dark-first theming with opt-in light mode
- React UI kit with 13 components (plain JS, no JSX)
- Preview HTML cards for token verification
- Brand assets (SVG logos and icons)
- Comprehensive design documentation (`DESIGN.md`)
