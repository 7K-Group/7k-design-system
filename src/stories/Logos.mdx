## Usage

```tsx
import logo from '7k-design-system/build/logos/logo-7k.svg';
import logoLight from '7k-design-system/build/logos/logo-7k-light.svg';

<img src={logo} alt="7K" />;
```

## Rules

- Logo is always uppercase `7K` — never lowercase.
- Use the color variant on dark canvas and the light variant on light backgrounds.
- Keep at least `24px` of clear space around the logo.
- Parent brand uses magenta; child projects swap the accent hue.
