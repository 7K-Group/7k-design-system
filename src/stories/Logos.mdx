## Usage

```tsx
import logo from '7k-design-system/build/logos/logo-7k.svg';
import logoLight from '7k-design-system/build/logos/logo-7k-light.svg';

<img src={logo} alt="7K" />;
```

## Rules

- Logo is always uppercase `7K` — never lowercase.
- Use the color variant on dark canvas and the light variant on light backgrounds.
- Keep at least `24px` of clear space around the logo.
- Parent brand uses magenta; child projects swap the accent hue.

## Project icons

Each project ships a stylized icon derived from the canonical base (`build/icons/icon-base.svg`, blobs tagged `blob-1`…`blob-5`). Exactly one blob is recolored with the project's accent token. Every variant ships in dark (`icon-*.svg`) and light (`icon-*-light.svg`) versions.

Static files are importable per project (`7k-design-system/icons/icon-inari.svg`). In React, use `<ProjectIcon />` — it resolves the icon from the active `ProjectProvider` scope only. Its fills are theme-aware tokens (`--icon-blob` flips white→black in light mode, accents shift 500→600), so one component covers both themes.
