## Typography Tokens

| Token               | Value                     | Usage               |
| ------------------- | ------------------------- | ------------------- |
| `--text-display`    | `clamp(48px, 8vw, 160px)` | Hero headlines      |
| `--text-h1`         | `4rem`                    | Page titles         |
| `--text-h2`         | `3rem`                    | Section headings    |
| `--text-h3`         | `2rem`                    | Subsection headings |
| `--text-h4`         | `1.5rem`                  | Minor headings      |
| `--text-body-lg`    | `1.125rem`                | Lead body text      |
| `--text-body`       | `1rem`                    | Body text           |
| `--text-body-sm`    | `0.875rem`                | Small body text     |
| `--text-caption`    | `0.75rem`                 | Captions            |
| `--text-mono-label` | `0.6875rem`               | Mono labels         |
| `--text-mono-body`  | `0.8125rem`               | Mono body           |

## Usage

```css
.my-component {
  background: var(--bg-elevated);
  color: var(--text-primary);
  border: 2px solid var(--border-default);
  padding: var(--space-4);
  font-family: var(--font-sans);
}
```
